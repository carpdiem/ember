EMBER · DARK FOREGROUND WARMTH

Transformed-first relaxed-L · full-system exact search

BRANCH EXPERIMENT · NOT CANONICAL · NO SINGLE SCALAR WINNER

How much hue can Ember's dark system lose?

This third pass steps both ink and surfaces toward the 3400K Light Mid-Depth hue philosophy: current keeps every shipped a/b vector; halfway interpolates all nine roles 50% of the way; full reaches the Light Mid-Depth hue level while keeping each role's shipped Oklab lightness and the dark palettes' decreasing-chroma hierarchy. Foreground lightness stays free within an explicit bound so transformed usability is never traded away, and categorical, terminal, and sequential banks are re-searched against each lane's exact selected system. Every value is scored only after exact Hex8 quantization.

Transformed usability first

Current release floors are hard penalties. Hue targets, chroma, and movement are softer competing objectives after usability.

Hue step, not lightness step

Surfaces move in hue (a/b) only; their dark lightness ladder, luminance ceilings, spacing, span, and text contrast gates still bind exactly.

Controlled dependencies

Identical seed pairs are reused across lanes. Sequential searches record a surface dependency fingerprint, so map invariance or change follows actual inputs rather than seed noise.
