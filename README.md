# Redshift Safe Palettes

A reproducible set of terminal, categorical, and sequential color systems engineered for warm-shifted displays.

> **Status:** active development. The first six audited palette families are being generated and documented now.

## Scope

Six families: dark and light variants for maximum macOS Night Shift, an approximately 2000 K software redshift, and an extreme astronomy-oriented red mode.

The project will publish machine-readable palette data, terminal themes, Matplotlib integration, tests, and the full derivation method.
