Ember · four palette profiles · verified under warm-display transforms

Color that stays articulate after your screen turns warm.

Night Shift and Redshift multiply each RGB channel by a different gain. At the 1200 K extreme, blue contributes nothing — colors that differ only in blue become identical. Ember authors terminal, UI, chart, and colormap roles that keep their identities under modeled 3400 K, 2000 K, and 1200 K transforms, and it states honestly how much capacity survives each one.

The night your grays turned to rust

A warm filter is not a tint laid over the screen. It is a per-channel amputation — and most palettes were never told.

Turn on Redshift at 1200 K and the blue channel of your display simply stops arriving. Whatever blue your theme commanded is multiplied by zero. Two syntax colors that differed only in blue now emit the same photons, and no amount of squinting brings the difference back.

Ember reverses the usual authoring order. It first pins hard targets in the transformed state — contrast, lightness geometry, minimum perceptual separation in Oklab — and only then, among the commanded colors that reproduce those targets, chooses the set with the strongest daytime identity. At 1200 K the blue channel is otherwise wasted, so Ember spends it freely on daytime distinction where the filter cannot see it.

Excellent daytime spacing cannot compensate for a nighttime collision, so Ember refuses to average the two into one score.

The same discipline governs what you are reading now. Body text is cream rather than pure white, because pure white becomes a louder transformed orange than a restrained cream — brightness spent on nothing. The near-black canvas beneath it is a warm neutral chosen so the filter finds little to distort. Links, emphasis, and the rule beside the pull quote spend chroma only where meaning lives.

And when the arithmetic says only four — or three — identities survive, Ember ships four or three, labels the aliases as aliases, and declines to pretend.

Set entirely in Ember roles: fg-0 body · fg-1 standfirst · fg-2 metadata · category-one links · category-two accent rule · bg-1 paper on bg-0 canvas.

Why cream, not white

Human vision carries fine detail through luminance, not chroma. Ember keeps the most frequent pixels — canvas and body text — warm-neutral, and reserves higher chroma for semantic accents. Every foreground role clears its contrast floor on every surface after the transform: 6.8:1 for primary text in the 3400 K dark family, 5.3:1 even at 1200 K.

Scene 02 — Code & terminal

Real install commands, the real Python API, and a live selection highlight on bg-5. The terminal accent line expands to every distinct ANSI accent the selected profile supports: six at 3400 K, four at 2000 K, and three at 1200 K.

Terminal exports ship for Alacritty, iTerm2, and Windows Terminal. Deep profiles repeat their supported capacities across the sixteen ANSI slots and label aliases as aliases instead of posing as extra colors.

Contrast is a release gate

Every foreground-capable terminal accent clears 4.5:1 against the terminal base background after its target transform. Accents are also gated against all three foreground roles, so a color cannot pass by colliding with muted text.

The light profile is not inverted

Scalar low→high always follows the authored ramp direction. In 3400K Light the ramp runs light→dark, so high terrain reads dark — deliberately. Reversing it to make peaks bright would break the family's scalar semantics.

Scene 05 — A photograph is not a scalar field

Pixels are mapped by Oklab perceptual lightness, stretched across the 1st–99th percentile, and mapped into the profile's 256 sequential samples. Where an authored ramp runs light→dark, generation reverses it for this photographic case only, so dark paint stays dark — the opposite convention from the Mars scalar map, on purpose.

The source is untouched: same crop, same geometry, no cosmetic handicap. Drag the wipe and judge the mapping against it directly.

Adopt Ember · MIT licensed · no build step, no registry, just files

Take the profile home.

Get the files

git clone https://github.com/carpdiem/ember.git
cd ember

Python users can skip the clone:

python -m pip install \
  "ember-palettes @ git+https://github.com/carpdiem/ember.git"

There is no PyPI package; install straight from GitHub.

Terminal themes

mkdir -p ~/.config/alacritty/themes
cp themes/terminal/alacritty/2000k-dark.toml \
   ~/.config/alacritty/themes/
  • Alacritty: import the copied TOML from alacritty.toml
  • iTerm2: Settings → Profiles → Colors → Import from themes/terminal/iterm2/
  • Windows Terminal: paste a scheme object from themes/terminal/windows-terminal/

CSS & JSON

<link rel="stylesheet" href="ember.css">
<section data-ember-palette="3400k-dark">
  …color: var(--ember-fg-0);
  background: var(--ember-bg-0);
</section>

palettes/ember.css exposes surfaces, foregrounds, categories, and 11 sequential stops. palettes/ember.json carries all 256 float samples, ANSI slots, gains, and measured results.
