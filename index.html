Design systems

Designing for the light that is left

Warm display transforms do not merely dim a palette. They collapse color channels unevenly, changing which differences remain available to perception.

A conventional interface is usually authored for the unshifted screen. Turn the display deeply warm and that interface is asked to solve a different problem with the same commanded colors. Reds may remain vivid while blues retreat; hues that were comfortably separate can arrive at the eye as near-neighbors.

Ember starts from the transformed state instead. Each family is optimized against a declared warm-screen model, then shipped with only the categorical identities that remain defensible there. The result is not maximal daytime variety. It is a smaller, more truthful vocabulary that continues to carry meaning.

Typography and surfaces still do most of the work. Body text uses the strongest foreground role; secondary prose steps down deliberately; rules and panels establish structure before accent color enters. That keeps the page readable even when a reader cannot—or should not have to—decode hue.

The same principle extends to charts and terminals: line style, markers, position, labels, and syntax weight remain part of the signal. Color is valuable, but it should never be the only witness.

“A color that exists only before the filter is not an identity. It is an accident of daylight.”

Ember’s deepest profile therefore exposes three categorical colors—not six weak imitations of a capacity the transform has already removed.

The mechanism

Design in the constrained state first.

A warm filter is not a translucent orange layer. It applies different gains to red, green, and blue, collapsing distinctions that ordinary daytime palettes depend on.

01

Model the surviving signal

Each family is tested under its target per-channel transform rather than judged only in commanded sRGB.

02

Protect identity and contrast

Hard transformed-state gates come first; daytime separation is improved only inside the surviving solution space.

03

Export one coherent system

The same authored families drive terminal themes, UI roles, chart colors, heatmaps, CSS, JSON, and Python.
